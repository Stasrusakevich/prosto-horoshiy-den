# Просто хороший день

Прототип приглашения на день рождения Стаса: 7 ноября 2026, 15:00–22:00, Quattro Space.

Сайт: https://stasrusakevich.github.io/prosto-horoshiy-den/

## Статус

Это открытый прототип для согласования дизайна и сценариев. Имена, ответы и пожелания в исходниках — демонстрационные. Ответы сохраняются только в localStorage текущего браузера; между устройствами не синхронизируются. Экран «Для Стаса» демонстрационный, без авторизации. Новые персональные ссылки работают только в браузере, где создана запись.

Не добавлять в публичный репозиторий настоящие списки гостей, контакты, пищевые ограничения, секреты или пароли. Перед рассылкой настоящих приглашений нужны серверное хранение ответов и защищённый кабинет организатора.

## Разработка

Статический HTML, CSS и JavaScript без зависимостей. Публикуемая папка — `docs/`.

Локальный просмотр: `node preview.mjs`, затем http://127.0.0.1:4183.

GitHub Pages публикует `main`, папку `/docs`. Изменения в этой ветке обновляют публичный прототип.

## Дизайн

Ноябрьская палитра: графит, тёплый серый, медь. Крупная типографика, прямые линии и кадр из кино. Уют создают содержание и компания.

## Перед реальным запуском

- Подключить общую базу, персональные токены приглашений и серверную авторизацию организатора.
- Удалить демонстрационные ответы и переключатель гостей.
- Уточнить вход, зал, парковку, меню напитков и время ужина.
- Проверить реальный ответ с двух независимых устройств.
