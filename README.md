# Просто хороший день

Приглашение на день рождения Стаса: 7 ноября 2026, 15:00–22:00, Quattro Space.

Основной адрес: https://stas-good-day.vercel.app/
Старая ссылка GitHub Pages перенаправляет на основной сайт, сохраняя открытый раздел.

## Возможности

- Общее приглашение, ручной ввод имени, ответ за себя или семью.
- Общие ответы, список подтвердивших гостей, песни и фотографии хранятся на сервере.
- Плейлист начинается с Adele — Rolling in the Deep от Стаса.
- До пяти фотографий на ответ, до 200 на мероприятие. JPG, PNG, WebP: браузер уменьшает снимок, сервер повторно проверяет его и удаляет EXIF.
- Галерея и список доступны всем по ссылке без аккаунта Vercel.
- Пищевые пожелания и возраст детей доступны только автору ответа и организатору.
- Личный случайный код позволяет редактировать свой ответ с другого устройства. В браузере хранится только этот код. При потере кода изменения вносит Стас через кабинет.
- Кабинет /#admin защищён отдельным паролем и подписанной HttpOnly-сессией на 8 часов: списки, CSV, напитки, пожелания, скрытие фото.

## Хранение и публикация

HTML/CSS/JS в docs/, Node.js API в api/index.mjs, приватное хранилище Vercel Blob. Данные гостей и фото не попадают в GitHub. JSON состояния обновляется условной записью по ETag; конфликт повторяется с новым чтением. Изменение одного ответа защищено номером версии.

Vercel project: stas-good-day. Node 24, регион fra1, output docs. Переменные сервера: BLOB_READ_WRITE_TOKEN, SESSION_SECRET, ADMIN_PASSWORD_HASH, APP_ORIGIN. По умолчанию данные в пространстве birthday. Секреты и файл admin-access.txt исключены из Git. Не публиковать их.

Git-интеграция Vercel пока не подключена: push обновляет репозиторий и GitHub Pages, но не Vercel. Выпускать проверенные исходники через Vercel API/CLI в существующий проект. Не переносить .env.local, .vercel, .local-data, admin-access.txt, node_modules в пакет публикации. GitHub Pages используется только как переход на основной адрес.

## Локальная проверка

1. npm ci.
2. Подготовить .env.local по .env.example, обязательно задать BIRTHDAY_DATA_NAMESPACE=birthday-qa.
3. npm run dev — http://127.0.0.1:4183.
4. npm test — проверка данных, прав и конкурентных записей.
5. node scripts/check-api.mjs — сквозной тест двух независимых гостей, загрузки и модерации фото. Нужен локальный admin-access.txt. Тест создаёт записи QA; идентификаторы сохраняются в .local-data/last-api-test.json для точечной уборки.

Не запускать тесты на рабочих данных без последующего удаления только созданных тестом записей. Локальные демонстрационные ответы старого прототипа не переносятся автоматически. Фотографии видны по ссылке; закрытой семейной авторизации нет. Автоматический внешний мониторинг не настроен.

## Дизайн

Ноябрьская палитра: графит, тёплый серый, медь. Крупная типографика, прямые линии и кадр из кино. Точное время ужина пока не объявлено.
